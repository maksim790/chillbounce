# Chillbounce

Chillbounce — планируемая кастодиальная криптовалютная платформа для хранения, пополнения, внутренних переводов и вывода тестовых активов Ethereum Sepolia.

Проект находится на этапе подготовки: требования и целевая архитектура описаны в документации, реализация приложения пока не подтверждена. Начните с [базы знаний](docs/Home.md).
