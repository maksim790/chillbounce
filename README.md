# Chillbounce

Chillbounce — планируемая кастодиальная криптовалютная платформа для хранения, пополнения, внутренних переводов и вывода тестовых активов Ethereum Sepolia.

Проект находится на этапе подготовки: требования и целевая архитектура описаны в документации, реализация приложения пока не подтверждена. Начните с [базы знаний](docs/Home.md).

## Разработка

TypeScript monorepo на pnpm Workspaces содержит технические React/Vite приложения `apps/shell` (host) и `apps/wallet` (remote и standalone). Общие библиотеки, backend и полноценные пользовательские интерфейсы ещё не созданы. Nx и другой task runner не используются.

Нужен Node.js `^22.13.0 || >=24.0.0` и pnpm версии из [package.json](package.json). Версии, совместимость и расширение конфигураций описаны в [руководстве по инструментам](docs/05-Engineering/Tooling.md).

Если pnpm уже доступен:

```sh
pnpm install
pnpm lint
pnpm format:check
pnpm typecheck
```

Для запуска без глобальной установки pnpm:

```sh
npm exec --yes --package=pnpm@12.18.0 -- pnpm install
```

В Windows PowerShell используйте `npm.cmd`, если политика выполнения блокирует `npm.ps1`. Аналогично можно запускать остальные команды: замените `install` на `lint`, `format:check` или другое имя script.

| Команда             | Действие                                                     |
| ------------------- | ------------------------------------------------------------ |
| `pnpm lint`         | ESLint для JS/TS, включая существующий конфигурационный файл |
| `pnpm lint:fix`     | ESLint с автоматическими исправлениями                       |
| `pnpm format`       | Форматирование файлов workspace, включая документацию        |
| `pnpm format:check` | Проверка форматирования                                      |
| `pnpm typecheck`    | Рекурсивный запуск `typecheck` scripts дочерних пакетов      |

Для воспроизводимой установки используйте `pnpm install --frozen-lockfile`.

Команды frontend: `pnpm dev` запускает shell на http://127.0.0.1:5173/ и wallet на http://127.0.0.1:5174/. `pnpm typecheck` проверяет оба приложения и их Vite-конфигурации. Для build/preview сначала скопируйте `apps/shell/.env.example` в `apps/shell/.env.local`, затем выполните `pnpm build` и `pnpm preview`. Dev и preview занимают одну пару портов и запускаются по очереди. Подробности и границы — в [Frontend](docs/02-System/Frontend.md).
