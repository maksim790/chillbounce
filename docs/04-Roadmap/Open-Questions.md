# Открытые вопросы

Статус: неизвестно по [исходному брифу](../06-Sources/Project-Brief.md) и осмотру пустого каталога. Перечень помогает уточнять проект и не задаёт дополнительных требований.

| Область | Что ещё требуется определить |
| --- | --- |
| Монорепозиторий | Package manager, инструмент управления, структура приложений и общих пакетов |
| Frontend | Фреймворк, сборщик, версии, federation runtime, shell/remotes, границы микрофронтендов, размещение admin-панели |
| Backend | Версия NestJS, границы модулей, публичные API и контракты |
| Авторизация | Способ входа, управление сессиями, восстановление доступа, роли и полномочия администратора |
| Данные и обработка | БД, транзакции, конкуренция, очереди, фоновые задачи, идемпотентность |
| Ledger | План счетов, проводки по операциям, точность сумм, резервирование, комиссии и лимиты |
| Активы | Список и адреса тестовых токенов, decimals, источник тестовых средств |
| Депозиты | Стратегия адресов, RPC-провайдер, число подтверждений, reorg, повторное сканирование |
| Внутренние переводы | Идентификатор получателя, допустимость перевода себе, ошибки и ограничения |
| Выводы | Комиссии сети, резервирование, nonce, подпись, повторные попытки, замена транзакций, статусы |
| Безопасность ключей | Генерация, хранение, доступ к подписи, резервное копирование и восстановление |
| Reconciliation | Источники сравнения, периодичность, обработка расхождений, оповещения |
| Эксплуатация | Окружения, CI/CD, хостинг, логи, метрики, восстановление после сбоев |
| Планирование | Приоритеты, критерии MVP, сроки и детальные критерии приёмки |

Не выбирайте варианты молча при описании текущей системы. Фиксируйте новые согласованные решения и связывайте их с [индексом решений](../03-Decisions/Decision-Index.md).
