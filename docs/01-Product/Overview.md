# Продукт Chillbounce

Статус: требования пользователя, реализация не подтверждена. Источник: [бриф от 2026-11-12](../06-Sources/Project-Brief.md).

## Назначение

Кастодиальная криптовалютная платформа позволяет пользователям хранить, пополнять, переводить и выводить тестовые активы через Ethereum Sepolia. Пользователь и администратор — роли, непосредственно следующие из заявленных сценариев; точная модель прав пока не определена.

## Основная функциональность

| Область | Требуемое поведение |
| --- | --- |
| Регистрация и авторизация | Создание аккаунта и вход в систему |
| Wallets | Балансы ETH и тестовых токенов, доступные и зарезервированные средства |
| Deposit | Выдача криптовалютного адреса; автоматическое обнаружение и зачисление поступивших тестовых активов в Sepolia |
| Internal Transfers | Переводы между пользователями Chillbounce без использования блокчейна |
| Withdrawal | Отправка тестовой криптовалюты на внешний Ethereum-адрес через блокчейн |
| История транзакций | Пополнения, переводы и выводы с суммами, статусами и деталями |
| Admin Dashboard | Мониторинг пользователей, кошельков, финансовых операций и ошибок |

## Требования к внутренним механизмам

- Double-entry ledger для учёта всех финансовых операций.
- Интеграция с Ethereum Sepolia.
- Обработка депозитов, внутренних переводов и выводов.
- Защита приватных ключей, контроль балансов и предотвращение двойных списаний.
- Reconciliation: сверка внутренних балансов с финансовым учётом и активами в блокчейне.

Способы реализации, модели данных и точные правила этих механизмов не согласованы.

## Сквозной сценарий

В исходном описании после слов «полный сценарий» последовательность отсутствовала. Следующая последовательность — вывод из перечисленных функций, а не дополнительное согласованное требование: регистрация и вход → просмотр кошелька и адреса пополнения → отправка тестовых активов в Sepolia → автоматическое зачисление → внутренний перевод другому пользователю → вывод на внешний адрес → просмотр истории. Для внутреннего перевода необходим получатель; способ его идентификации пока неизвестен.

## Границы определённости

Админ-панель заявлена для мониторинга. Ручное изменение балансов и разрешение выводов администратором не заявлены. Поддержка mainnet и реальных активов не согласована. Список токенов, комиссии, лимиты и жизненные циклы операций требуют уточнения в [открытых вопросах](../04-Roadmap/Open-Questions.md).
