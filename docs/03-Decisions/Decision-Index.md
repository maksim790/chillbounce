# Индекс решений

Источник всех перечисленных решений — [исходный бриф пользователя](../06-Sources/Project-Brief.md), 2026-11-12. Статус: заданы пользователем, приняты как ограничения будущего проекта; реализация не подтверждена. Обоснования и рассмотренные альтернативы не указаны, поэтому не реконструируются.

| Решение | Статус и отношение к реализации | Обоснование |
| --- | --- | --- |

| Ethereum Sepolia и тестовые активы для пополнения и вывода | Задано пользователем; интеграция не обнаружена | Не указано |
| Монорепозиторий | Задано пользователем; структура пакетов не определена | Не указано |
| Микрофронтенды с Module Federation | Задано пользователем; состав и инструменты не определены | Не указано |
| Backend — монолит NestJS | Задано пользователем; модули не определены | Не указано |
| Double-entry ledger для финансового учёта | Задано пользователем; счета, проводки и хранилище не определены | Не указано |

Это индекс текущих явно заданных решений, а не восстановленная история ADR. Существующих ADR, RFC и иных записей обоснований в каталоге не обнаружено. Новые существенные решения следует фиксировать с фактическими причинами, статусом и источниками.
