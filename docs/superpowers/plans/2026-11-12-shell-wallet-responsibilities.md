## Global Constraints

- Только документация: без интерфейсов, исходников, зависимостей, запуска приложений и browser checks.
- Shell — каркас, общая навигация, экраны регистрации/входа/выхода и состояние сессии. Wallet — все пользовательские сценарии кошелька. Backend — авторитетные данные и проверки.
- Crypto остаётся без определённого назначения; admin — будущий мониторинг. Не выбирать router, auth mechanism, API, transport сессии или новые финансовые правила.
- Продолжать feature/document-shell-wallet-responsibilities; исполнение начинается только после отдельного решения пользователя. Один согласованный документационный результат — один логический коммит, затем интеграция по AGENTS.md.

## Review Focus

1. Будущие экраны не названы реализованными — сопоставить текст с App/Wallet и текущим Frontend.
2. Финансовая ответственность не попала в Shell или клиентскую проверку прав — проверить таблицу обязанностей и backend-границу.
3. Crypto не дублирует Wallet и не получает выдуманную функцию — проверить roadmap и открытые вопросы.
4. Состояние сессии не выдано за готовый технический контракт — явно оставить способ передачи/хранения и router открытыми.
5. Изменения не создают противоречий с прежними решениями и битых ссылок — сохранить историю и выполнить документационные проверки.
